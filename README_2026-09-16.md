# Prompt Builder 0.1.67

## Taxonomy source
`prompt_templates.json` is the single source of truth for `Category` and `AI Tool`. These values are derived dynamically for Builder, Templates filters, and the template editor. They are intentionally not stored in `config.json`.

## GitHub Pages
Open `index.html` via GitHub Pages. User API keys, presets and builder state are stored in localStorage.

## Local
Use `start.bat` (Windows), `start.command` (macOS) or `start.sh` (Linux). The local launcher starts a small static Node server and opens `http://localhost:3000`.

## Template data model

`prompt_templates.json` is the primary source of built-in templates and their `id`, `section`, `category`, and `agent` values. Browser `localStorage` stores only user-created templates (`CanBeDeleted: true`) as additions. User template IDs start after the maximum built-in template ID.


Template storage model (0.1.67): prompt_templates.json is the immutable primary source. User-created templates are stored separately: localStorage on GitHub Pages, user_templates.json in local mode.


## PB0.1.67
- Built-in prompt templates are immutable; user templates are the only mutable template records.
- Builder taxonomy fields Section, Category and AI Tool are sourced from prompt_templates.json plus user templates.
- GitHub Pages exposes Clear localStorage with a red hover state.
