# Prompt Builder 0.1.53

Current GitHub Pages static build. Mutable user data is stored in browser localStorage.

## Local storage
- API keys: `pb-provider-credentials-v1` (per provider, browser-local, not encrypted)
- AI settings/models: `pb-ai-settings`
- Builder state: `pb-builder-state-v1`
- Presets: `pb-presets-v1` (max 20)
- Prompt templates: `pb-prompt-templates-v1`
- Builder config/taxonomy additions: `pb-builder-config-v1`

## GitHub Pages deployment
Commit the files in this folder to a repository and enable GitHub Pages for the branch/folder containing `index.html`.

## Important
AI requests are performed directly from the browser to the selected provider. The provider must permit browser CORS requests from the GitHub Pages origin. Ollama also needs to permit requests from the browser origin.

API keys are intentionally stored in localStorage because this is a static, per-user deployment. They are not stored in repository files. Do not use this mode on an untrusted/shared machine.
